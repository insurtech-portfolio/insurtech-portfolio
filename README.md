
# Portfolio Insurtech

Portfolio profesional enfocado en tecnología aplicada a la industria aseguradora (Insurtech), procesos de negocio, análisis funcional, arquitectura de software y desarrollo de aplicaciones.

## Acerca del proyecto

Este portfolio reúne una colección de proyectos independientes y de alcance reducido (MVP), orientados a demostrar conocimientos prácticos del negocio asegurador y de las tecnologías utilizadas en la industria.

## Objetivos

- Comprender los principales procesos del negocio asegurador.
- Transformar necesidades de negocio en especificaciones funcionales.
- Diseñar bases de datos relacionales y APIs REST.
- Desarrollar aplicaciones backend y frontend.
- Implementar reglas de negocio, motores de tarifas e integraciones.
- Aplicar buenas prácticas de ingeniería de software y gestión de proyectos.

## Proyectos

| Proyecto | Descripción | Estado |
|---|---|---|
| Insurance Core | Gestión de clientes, productos y pólizas | Planificado |
| Pricing Engine | Motor de tarifas y reglas de elegibilidad | Planificado |
| Claims Management | Gestión del ciclo de vida de siniestros | Planificado |
| Insurance Audit | Auditoría y trazabilidad de operaciones | Planificado |
| Insurance Integrations | Integraciones, eventos y webhooks | Planificado |
| Insurtech Analytics | Indicadores y análisis de información aseguradora | Planificado |

## Entorno de desarrollo y despliegue

El desarrollo se realizará prioritariamente en un entorno local.

Para posibles despliegues en la nube se utilizarán:

- Neon: alojamiento de bases de datos PostgreSQL.
- Render: alojamiento de backend y servicios.
- Vercel: despliegue de aplicaciones frontend.

## Documentación

Cada proyecto contará con documentación funcional y técnica, incluyendo:

- Requerimientos y reglas de negocio.
- Procesos y casos de uso.
- Historias de usuario y criterios de aceptación.
- Modelo de datos y diccionario de datos.
- Arquitectura y especificaciones de APIs.
- Pruebas y documentación de implementación.

## Alcance y finalidad

Este portfolio tiene fines educativos y profesionales. Su objetivo es demostrar conocimientos del dominio asegurador, análisis funcional, diseño de soluciones y desarrollo de software.

No representa el sistema productivo de una compañía de seguros real.
